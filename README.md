The SpongeBob SquarePants Movie – PC Recompilation

A community-oriented PC recompilation project based on the GameCube version of The SpongeBob SquarePants Movie.

Project information

- Developer: Krozber Studios
- Platform: Windows 10/11 64-bit
- Original platform: Nintendo GameCube
- Project base: WR3CKINGBALL/tssm-recomp

Features

- Native PC recompilation
- Windows executable
- Planned Windows installer
- Desktop shortcut
- Future version releases

Requirements

- A legally obtained copy of the original game.
- Required game files extracted locally.
- Compatible Windows 64-bit system.

Installation

Installation instructions and releases will be published here when available.
